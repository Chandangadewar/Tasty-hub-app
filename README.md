# Tasty Hub App

A full-stack web application built to practice DevOps implementation including containerization, CI/CD, and cloud deployment.

## Overview

Tasty Hub is a full-stack application built using modern web technologies.
Its primary purpose is to serve as a DevOps practice project for implementing production-grade workflows.

## Tech Stack

### Frontend
- React

### Backend
- Node.js
- Express.js

### Database
- MySQL

### DevOps (Planned)
- Docker
- Docker Compose
- AWS
- Kubernetes

## Project Objectives

- Containerization using Docker
- Multi-container setup using Docker Compose
- CI/CD pipeline implementation
- Cloud deployment on AWS
- Infrastructure as Code
- Kubernetes orchestration
